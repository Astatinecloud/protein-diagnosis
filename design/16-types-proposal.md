# 設計: 科学的4文字分類による16タイプ診断（v2）

作成: Claude（2026-11-05）。ユーザーが分類表を承認済み。データは `design/proteins.json`（version 2）。実装は Codex。

## 1. 4文字の意味（たんぱく質の科学的性質）

| 位置 | 文字 | 判定の基準 |
|---|---|---|
| 1 | **E** 酵素 / **N** 非酵素 | 主な働きが化学反応の触媒か |
| 2 | **B** 膜結合 / **S** 可溶性 | 細胞膜などに埋まって・結合して働くか |
| 3 | **U** 単量体 / **T** 多量体 | 1本の鎖で働くか、複数の鎖が集まって働くか（PDBの生物学的集合体に合わせる） |
| 4 | **H** ヒトももつ / **X** ヒトはもたない | 同じ働きをする同じ仲間のたんぱく質がヒトの体にあるか |

たんぱく質の4文字は科学的事実。判断が分かれうるものは各たんぱく質の `classificationNote` に理由を書き、画面に表示する。

## 3. 性格の質問との対応（ゲーム上のたとえ）

質問9問・配点は変更しない。8特性の標準化スコア z から4つの軸スコアを作る。

| 文字 | 性格のたとえ | 軸スコア（正なら左の文字） |
|---|---|---|
| E / N | 自分から変化を起こす / ぶれずに役目を果たす | z行動 − z安定 |
| B / S | 境界で見極める・守る / どこへでも溶け込む | z守り − z柔軟 |
| U / T | ひとりでやりきる / 仲間と組む | z好奇心 − z協調 |
| H / X | 身近な人を支える / 個性で勝負する | z支援 − z表現 |

「たんぱく質の4文字は科学的事実、あなたの性格との結びつきはゲーム上のたとえ（科学的な性格検査ではない）」と画面に明記する。

## 4. 判定アルゴリズム

1. 生スコア u と標準化 z は現行どおり。
2. 軸スコア d（4次元）を上の表で計算する。
3. 質問データから d の共分散行列 Σ を解析的に計算する。各質問の4択は等確率で独立とみなし、質問ごとの共分散を足し合わせる（全パターンの列挙は不要）。
4. ZCA 白色化 d' = Σ^(−1/2) d で軸どうしの連動を打ち消し、d'_i > 0 なら左の文字、そうでなければ右の文字を選ぶ。
5. 4文字コードと `typeCode` が一致するたんぱく質を結果にする。
6. Σ が特異で計算できない場合は補正なし（単位行列）。全特性 z=0 の場合は現行どおり回答から決まる番号（mod 16）で決める。

全262,144通りの検証結果: 16種類すべて到達、各 5.90%〜6.53%（理想 6.25%）。補正なしでは 1.78%〜10.32% と偏る。
