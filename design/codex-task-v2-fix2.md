# Codex への修正依頼（v2 レビュー指摘 #2）

結果画像PNG（src/export/resultImage.ts）の高さが内容に応じて伸び、光化学系IIでは 1080×2264 になっている。
仕様は **常に 1080×1920**（SNSのストーリー向け）。次のとおり直すこと。

1. キャンバスは常に 1080×1920 に固定する。
2. 16種類すべてで、文字が重ならず、キャンバスからはみ出さないようにレイアウトを調整する。
   - 4文字の説明は、PNGでは1行の簡潔な表記にしてよい（例「EBTX＝酵素・膜結合・多量体・ヒトはもたない」。文言は src/domain/typeCode.ts の定義から生成）。
   - PNG では classificationNote を省略してよい（結果ページには表示済み）。
   - 構造画像・タイトル・タイプ名・キャッチコピー・性格・豆知識・QR・クレジット・注意書き（4文字の注意書きと「科学的な性格検査ではありません」）は残す。長い文章は行数の上限を決めて「…」で切る既存の仕組みを使う。
3. テスト: 16種類すべてで生成されるPNG（またはキャンバス）が 1080×1920 であること、描画した各テキストの領域が重ならずキャンバス内に収まること（描画位置を記録するなど、jsdom で検証できる方法で）。
4. コードは既存の書き方（2スペースインデント、120文字以内）で読みやすく書く。
